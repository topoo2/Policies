# Privacy Policy for  Bot

Last updated: July 13, 2026

## Data We Collect
- **User ID**: For moderation, economy, and premium features
- **Guild ID**: For server-specific settings (prefixes, configs)
- **Message Content**: Only when a command prefix is detected (for command parsing)
- **Voice State**: For voice channel management features

## How We Use Data
- To provide bot functionality (moderation, anti-nuke, voice, economy)
- To store server preferences (prefixes, settings)
- To track premium subscriptions

## Data Storage
- Data is stored in SQLite databases on the host server
- We do not sell or share your data with third parties

## Data Deletion
- Remove the bot from your server to delete guild-specific data
- Contact our support server for user data deletion requests
